¿Qué es el seeMote Cube?

El seeMote Cube es un dispositivo físico de entrada espacial desarrollado por la empresa DFRobot. Está diseñado para utilizarse con Apple Vision Pro y aplicaciones del sistema visionOS.

Su objetivo es permitir que los desarrolladores incorporen controles físicos a los entornos digitales tridimensionales. De esta manera, el usuario puede mover el dispositivo, pulsar botones y recibir respuestas mediante vibraciones para interactuar con los elementos virtuales.

Características principales

  • Seguimiento espacial de 6 grados de libertad (6DoF).
  • Seis botones físicos programables.
  • Motor de vibración para ofrecer respuesta háptica.
  • Batería recargable y conexión USB-C.
  • Compatibilidad con Apple Vision Pro y visionOS.

    • Fue presentado en junio de 2026 y comenzó a comercializarse el 29 de julio de 2026, con un precio anunciado de 299 dólares.

    ¿Cómo funciona?

    El funcionamiento del seeMote Cube consiste en utilizar sus movimientos, botones y vibraciones para interactuar con aplicaciones compatibles de Apple Vision Pro. Para ello, los desarrolladores deben integrar sus funciones en las aplicaciones que quieran utilizarlo.

    Lo interesante es que no hace falta utilizar solamente las manos o los ojos para interactuar. También podemos coger el cubo, moverlo, girarlo y utilizar sus botones.

    Sus principales funciones

    • Movimiento: el dispositivo detecta cómo lo movemos y giramos. Estos movimientos se pueden trasladar a los objetos que aparecen en la pantalla.
    • Seis botones: tiene seis botones físicos que se pueden configurar para realizar diferentes acciones, como seleccionar, confirmar o cambiar de herramienta.
    • Vibraciones: incorpora un sistema que hace que el dispositivo vibre cuando la aplicación lo indica. Así, el usuario puede recibir una respuesta sin tener que mirar constantemente la pantalla.

    Un ejemplo de uso

    Imaginemos que una persona está utilizando un programa para visualizar un objeto en tres dimensiones. Puede mover el seeMote Cube para cambiar la posición de un elemento virtual, pulsar uno de sus botones para seleccionar una opción y recibir una vibración cuando la acción se haya realizado.

    De esta manera, el dispositivo combina movimientos, botones físicos y vibraciones para hacer que la interacción con los elementos digitales sea más completa.

    Interacción persona-ordenador

    El seeMote Cube ofrece una forma diferente de interactuar con los dispositivos digitales, ya que permite combinar movimientos físicos, botones y vibraciones.

    Normalmente, cuando utilizamos un entorno virtual, podemos interactuar mediante gestos con las manos, la mirada o controles tradicionales. Con este dispositivo también podemos utilizar un objeto físico que tenemos en la mano para realizar acciones.

    ¿Cómo mejora la interacción?

    • Más control: los botones físicos permiten realizar acciones concretas sin depender únicamente de los gestos.
    • Respuesta del dispositivo: las vibraciones permiten recibir información mediante el tacto.
    • Interacción espacial: los movimientos y giros del cubo pueden utilizarse para controlar elementos en tres dimensiones.
    • Más posibilidades: los botones se pueden configurar para adaptarse a diferentes aplicaciones y necesidades.

    Por tanto, el usuario no solo recibe información visual, sino que también puede utilizar el movimiento y el tacto para comunicarse con el entorno digital.

    Ventajas y beneficios

    El seeMote Cube puede aportar varias ventajas a la hora de interactuar con entornos digitales, especialmente cuando se utilizan aplicaciones tridimensionales.

    Principales ventajas

    • Mayor precisión: permite utilizar botones físicos y movimientos para controlar diferentes acciones.
    • Información mediante el tacto: las vibraciones ayudan a recibir respuestas sin depender solamente de la vista.
    • Personalización: sus seis botones se pueden configurar según las necesidades de cada aplicación.
    • Interacción más completa: combina diferentes formas de comunicación con el entorno virtual.

    ¿A quién puede beneficiar?

    Puede resultar útil para desarrolladores que crean aplicaciones para Apple Vision Pro, así como para usuarios que trabajan con modelos y objetos en tres dimensiones o utilizan experiencias de realidad mixta.

    En mi opinión, lo más interesante de este dispositivo es que incorpora controles físicos en un entorno donde muchas acciones se realizan mediante gestos o movimientos de las manos. Esto ofrece otra posibilidad para interactuar con la tecnología.
